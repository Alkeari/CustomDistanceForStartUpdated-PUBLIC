# Changelog

What changed in Custom Distance for Start - Updated, newest first. Only changes a player can notice are listed.

## v1.0.1 - 2026-10-18

- Fixed: A new game no longer stops with a runtime error on world creation when Gathering Storm is not active.
- Fixed: The starting distance options now take effect in Gathering Storm games, where the game's own placement had been used instead.
- Changed: When a civ's region has no land far enough from the civs already placed, it now starts on the most fertile land anywhere on the map that is far enough, or the farthest land when none is.

## v1.0.0 - 2025-02-14

- Added: Three Advanced Setup options set the minimum starting distance between civilizations, between city-states, and between civilizations and city-states.
